# Short Video Skills

A Claude Code plugin that helps you choose and safely install the 8 most useful animation and video skill packs for TikToks, Reels and YouTube Shorts.

Each pack downloads from its original creator, so you always get the current version. This plugin only holds the guide.

## Install

You need [Claude Code](https://claude.com/claude-code). Open Terminal, and run these two lines one at a time:

```bash
claude plugin marketplace add High56/short-video-skills
```

```bash
claude plugin install short-video-skills@short-video-tools
```

Then start a new Claude Code session.

## Use it

Ask Claude in plain words:

- "What's the best skill for making TikToks?"
- "Install HyperFrames for me."

Or type `/short-video-skills:guide`.

Claude explains what each pack does and asks for your yes before installing anything.

## The packs

| Pack | Good for |
|---|---|
| [HyperFrames](https://github.com/heygen-com/hyperframes) | All-round animated video |
| [Video Shotcraft](https://github.com/Vincentwei1021/video-shotcraft) | Cinematic product promos |
| [Lemo Opuscar](https://github.com/lemomo-ai/lemo-opuscar) | 66 film styles made in code |
| [Remotion Skills](https://github.com/remotion-dev/skills) | Official skills for Remotion |

| [Video Agent Skills](https://github.com/Melvynx/video-agent-skills) | Scripting, research and editing for short videos |
